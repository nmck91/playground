## Story Description

Implement a knockout cup competition system that runs parallel to the league season, adding strategic depth and additional trophy opportunities. The cup will feature 20 teams (the league teams) in a single-elimination tournament with extra time and penalties for drawn matches.

---

## Business Value

**Why This Matters**:
- **User Engagement**: Adds variety and unpredictability to the season
- **Strategic Depth**: Players must balance league and cup priorities
- **Quick Win Feature**: High-value user-facing feature that's fun to play
- **Trophy Collection**: Expands achievement system with cup silverware
- **Financial Impact**: Prize money adds another dimension to budget management
- **AI Behavior**: Demonstrates intelligent squad rotation for cup matches

---

## Current State Analysis

**Current System**:
- Only league fixtures exist (38 matches per season)
- Match simulator handles single matches only
- No knockout tournament logic
- No extra time or penalty shootout mechanics
- Fixtures generated by SeasonManager are league-only
- Trophy cabinet exists but only shows league titles

**Limitations**:
- No variety in competition format
- Season can feel repetitive (all league matches)
- Limited trophy opportunities
- No fixture congestion management needed
- AI doesn't need to prioritize different competitions


### Enhanced Match Simulator

**MatchSimulator** - Extend for knockout matches:
```typescript
export class MatchSimulator {
  // Existing league match simulation
  simulateMatch(...): MatchResult;

  // NEW: Knockout match with extra time/penalties
  simulateKnockoutMatch(...): KnockoutMatchResult {
    let result = this.simulateMatch(...);

    if (result.homeScore === result.awayScore) {
      result = this.simulateExtraTime(result);

      if (result.homeScore === result.awayScore) {
        result = this.simulatePenalties(result);
      }
    }

    return result;
  }

  // NEW: Extra time (2x 15 min periods)
  private simulateExtraTime(match: MatchResult): MatchResult;

  // NEW: Penalty shootout
  private simulatePenalties(match: MatchResult): MatchResult;
}
```

**New Types** (`libs/football-director-engine/src/lib/types.ts`):

```typescript
export interface CupCompetition {
  id: string;
  name: string;
  season: number;
  currentRound: CupRound;
  rounds: CupRound[];
  winner?: Team;
  runnerUp?: Team;
  prizePool: PrizeMoney;
}

export interface CupRound {
  roundNumber: number; // 1=R1, 2=R2, 3=R3, 4=QF, 5=SF, 6=Final
  roundName: string; // "Round 1", "Quarter-Finals", etc.
  fixtures: CupFixture[];
  weekNumber: number; // When this round is played
  completed: boolean;
}

export interface CupFixture {
  id: string;
  homeTeam: Team;
  awayTeam: Team;
  round: number;
  weekNumber: number;
  result?: CupResult;
}

export interface CupResult extends MatchResult {
  wentToExtraTime: boolean;
  wentToPenalties: boolean;
  penaltyScore?: {
    home: number;
    away: number;
  };
  winner: Team;
  loser: Team;
}

export interface PrizeMoney {
  round1: number;    // £10,000
  round2: number;    // £25,000
  round3: number;    // £50,000
  quarterFinal: number; // £100,000
  semiFinal: number;    // £250,000
  runnerUp: number;     // £500,000
  winner: number;       // £1,000,000
}

// Add to GameState
export interface GameState {
  // ... existing fields
  cupCompetition?: CupCompetition; // Optional for first season
  cupHistory: CupCompetition[];    // Past cup competitions
}
```

## Acceptance Criteria

### Must Have

✅ **AC1: Cup Competition Setup**
- Cup competition generated at season start with 20 teams
- Random draw creates balanced knockout bracket
- 6 rounds: R1 (10 matches), R2 (5 matches), R3 (4 matches), QF (2 matches), SF (2 matches), Final (1 match)
- Each round scheduled for specific week in season calendar

✅ **AC2: Knockout Match Mechanics**
- Drawn matches go to extra time (2x 15 min)
- If still drawn, penalty shootout determines winner
- Penalty shootouts are realistic (each team takes 5 penalties minimum)
- Extra time and penalties tracked in match result

✅ **AC3: Tournament Progression**
- Winners advance to next round automatically
- Losers are eliminated from cup
- Player team can win or be eliminated
- AI teams participate and can win the cup

✅ **AC4: Integration with Season**
- Cup fixtures don't conflict with league fixtures
- Cup weeks are clearly marked in calendar
- Weekly simulation processes cup matches correctly
- Both league and cup results shown after simulation

✅ **AC5: Rewards System**
- Prize money awarded for each round reached
- Winner receives cup trophy
- Trophy appears in trophy cabinet
- Cup wins tracked in club history/records

⭐ **AC6: UI/UX**

## Risks and Mitigation

**Risk 1: Tournament Bracket Logic Complexity**
- **Likelihood**: Medium
- **Impact**: Medium
- **Mitigation**:
  - Use simple single-elimination format (no seeding)
  - Handle byes if odd number of teams
  - Test bracket generation thoroughly
  - Consider using well-established algorithm

**Risk 2: Extra Time/Penalties Add Simulation Time**
- **Likelihood**: Medium
- **Impact**: Low
- **Mitigation**:
  - Keep penalty simulation simple (not full match simulation)
  - Benchmark performance with cup included
  - Optimize if needed (target: <100ms per cup match)

**Risk 3: Cup Fixtures Conflict with League Schedule**
- **Likelihood**: Low
- **Impact**: High
- **Mitigation**:
  - Carefully schedule cup rounds on non-league weeks
  - Test fixture generation extensively
  - Ensure SeasonManager handles both correctly

**Risk 4: Save/Load Issues with Cup Data**
- **Likelihood**: Low
- **Impact**: High
- **Mitigation**:
  - Make cupCompetition optional in GameState
  - Add migration logic if needed
  - Test save/load with and without cup
  - Preserve backward compatibility with existing saves

**Risk 5: UI Complexity for Bracket Display**
- **Likelihood**: Medium
- **Impact**: Low
- **Mitigation**:
  - Start with simple list view (functional)
  - Enhance to visual bracket later if time allows
  - Focus on functionality over aesthetics initially
  - Use responsive design for mobile compatibility
